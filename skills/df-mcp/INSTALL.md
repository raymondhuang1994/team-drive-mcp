# 给同事的安装说明

1. 在公司 Skill Hub 的“ZIP / .skill”入口上传完整 ZIP。压缩包根目录直接包含一个 SKILL.md，以及 scripts/、runtime/ 等文件夹，不额外套 df-mcp/ 目录，也不要只上传 SKILL.md。
2. Hub 负责生成和分发完整安装包。把包安装到公司允许的本地电脑 GPT 中，再说：**“初始化 DF 资料助手。”**
3. 选择 **A 团队公盘 / 云盘** 或 **B 本地磁盘**，也可以直接提供文件夹地址或 SharePoint / OneDrive 文件夹链接。
4. 核对助手展示的资料位置、包含子文件夹范围及独立本地索引位置，确认后开始建立索引。
5. 等待“索引就绪”，查看跳过或读取失败的文件，然后开始提问。

A 默认查找电脑已连接的 Digital Finance / Digital Finance_0。找不到时，打开资源管理器，进入需要读取的文件夹，从地址栏复制完整路径；截图里的省略路径不能用于配置。

同事安装的是完整分发包，脚本随包带到本地电脑执行，不在 Hub 内执行。手动解压时先新建独立的 df-mcp 安装目录，再将 ZIP 内容解压进去；不要把脚本、runtime 或 references 单独移走。

源资料只读。索引和解析缓存保存在本机独立目录，可能包含原文片段；回答时必要片段会交给公司 ChatGPT。默认 Windows 位置为 `%LOCALAPPDATA%\df-mcp`，可以另选普通本地目录。

微软云盘需要公司预先批准的应用配置，并由本人在微软页面登录。不在聊天里发送密码、令牌或分享密钥。某些短分享链接无法直接解析时，助手会引导从已授权文档库选择文件夹。

## 环境要求

完整 ZIP 附带解析依赖，不附带 Python 解释器。需要公司批准的 Python 3.9+、脚本执行、指定目录读取和索引目录写入能力。网络公盘需要在 Windows 上运行，并能连接公司网络/VPN；能看到磁盘图标不等于当前能读取文件。

如果使用纯云端 ChatGPT，需有公司批准的本地执行连接或资料服务。ZIP 本身不会连接公司电脑、安装隧道或开通微软权限。缺少运行环境时请把助手给出的检查结果交给 IT，不要随意下载其他程序。

以后可说：“添加一个资料库”“刷新资料”“查看读取失败的文件”“查看索引位置”。默认位置的已配置资料库可以重新发现；使用自定义索引目录时，请保留目录地址，新的聊天可用该地址查找配置。更换或清理索引须单独确认，不能在运行时手动移动数据库文件。
