# 0.6：完整 Skill ZIP 与团队资料来源

0.6 将原 MCP 的读取核心复用于可导入的完整 Skill ZIP。用户只看两个选项：A 团队公盘/云盘（Digital Finance、SharePoint、OneDrive），B 本地磁盘；可以回复字母或直接提供文件夹地址/链接。UI 合并不改变各来源的授权和协议。

## 包内和运行条件

- SKILL.md、中文首次使用规范、Python CLI、核心、解析依赖、IT 配置示例、完整性 SHA256 清单。
- 没有 Python 解释器、Node、真实源资料、索引、token 或员工配置。
- Python 3.9+ 与获准本地脚本能力；Windows 网络盘需要在 Windows 当前用户会话下执行。
- 原 stdio MCP 接口及 13 个工具继续保留，Node 22+ 安装流程仍可使用。
- 未安装到当前用户现有 Skill/MCP 配置；导入 ZIP 与切换现有连接是两个步骤。

在固定依赖环境打包：

```sh
python scripts/build-skill.py --output .build/df-mcp-0.6.0.zip
```

构建器只复制允许的源码、资源及三个固定版本的纯 Python 依赖，同时保留第三方许可证；不扫描或打包用户状态。输出路径已存在时拒绝覆盖。

## 初始化和持久索引

probe / classify / plan 是只读检查；apply 要求确认且重算计划、重新核验来源。只在确认后创建独立本地 profile。状态和源、程序目录不得互相包含，不能把数据库放在同步盘或网络盘。默认路径沿用平台私有应用数据目录，支持 --state-dir。

每个来源独立配置；同一用户的不同聊天复用同一索引。profiles 在默认/明确指定状态基目录中有界列出已有配置，不扫描全磁盘。自定义状态位置由用户/公司保存地址，不另建隐蔽默认注册表。修改来源不原地重绑旧索引。

CLI 分页必须在同一调用内使用 --paginate；游标不能跨进程复用。输出/page预算耗尽会明确显示不完整，中途访问失败丢弃前面页，不拼接成成功数据集。启动、扫描中、索引完成及解析缺口分别报告。

## 三类适配器

**local**：普通本地目录，保留原来的只读和路径限制。

**windows_share**：新增 Windows UNC/映射共享盘访问，使用当前用户网络身份，不创建映射、不处理密码。显式配置才能启用；local 和索引存储限制不放宽。共享目录版本/访问变化在读取和候选使用前核验；遍历不完整或断网不能导致批量删除旧索引。Windows 原生 SMB I/O 可能等待操作系统超时，遍历预算不等于硬中断网络请求。可验证的普通 SMB/DFS 目录使用严格句柄与目标校验；暴露为 reparse 或不稳定/嵌套 referral 的布局会被拒绝，需 IT 提供获批直接共享路径。公司 DFS referral、VPN、凭证及真实文件行为需实机验收。

**microsoft_graph**：保留 0.5 授权、下载和版本校验。新增账号初始化与只读目录发现：登录无需事先知道 drive/folder；用户选定目录后才绑定资料 profile。/me/drives 不是所有共享库。未知站点查询可能需要已有的 Sites.Read.All；程序不自动增加 scope。分享短链 /shares 的文档权限含写入，因此这里不调用、不兑换权限；可以选已有目录或使用 IT 给出的明确 ID。凭证仅存在独立本机账号缓存，Windows 使用 DPAPI。

## 本地与云端使用

完整本地路径是 Skill → Python CLI → 本机 broker/core → 来源；索引独立保存在公司电脑。

获准的云端任务如果已经具有连接到该电脑的本地执行工具，可以调用相同脚本。纯云容器不能直接读取个人电脑路径，也不能声称临时容器目录是长期本地索引。本包不包含远程 HTTP MCP/隧道部署或多用户服务；若公司最终只允许纯云端，需要另行配置已批准的本地接入或部署资料服务。任何集中服务必须核验真实请求者与各来源权限，不能共享管理员账号向全部员工放出文件名、摘要或正文。

## 验证边界

自动验证使用虚构临时资料与模拟 Graph 响应，包含初始化确认、来源隔离、版本变化、分页、错误、权限与打包后独立运行。发布记录会列出实际运行的测试与平台；它们不代替公司 Windows 公盘、真实微软租户与 ChatGPT ZIP 上传入口的验收。OCR 和实际语义模型验收不属于本次启用范围。

Windows 自定义状态目录仍依赖公司设定的目录访问权限，本版本没有声称已审计或重置其 DACL；默认用户应用数据目录更适合每人独立保存。
